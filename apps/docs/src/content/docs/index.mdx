Kerna is an Agent-first page builder for the EmDash CMS. Agents compose Pages
from a site's Design System; Reviewers accept or reject their Proposals.

The core package is unreleased and under development. These guides cover its
local workspace API: pure TypeScript rules that run without a CMS.

## Start with a Proposal

[Create your first Proposal](/guides/first-proposal/) to preview a conflict and
accept only the applicable Operation. The complete example runs locally with
Node 24 and Vite+.

When connecting storage, follow [Save Proposal decisions safely](/guides/persist-proposal-decisions/)
to authorize actions and save Page and Proposal changes atomically.

## Look up a contract

- [Proposal API](/reference/proposals/): inputs, results and decision lifecycle.
- [Operations](/reference/operations/): typed changes, destinations, guards and limits.
