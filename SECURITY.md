# Security policy

Kerna is unreleased. There are no supported production versions or guaranteed security response times yet. Fixes target the current development code; do not deploy it as a production CMS extension.

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/kodlabstdio/kerna/security/advisories/new), or email [kodlabstudio@gmail.com](mailto:kodlabstudio@gmail.com). Do not put exploit details, credentials or private content in a public issue or pull request.

Include the affected commit, a minimal reproduction, expected impact and any suggested fix. The founders will investigate, coordinate a fix and agree on disclosure with the reporter. This is a best-effort process while the project is under development.
