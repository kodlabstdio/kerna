# @kodlab/kerna

Kerna's native EmDash integration, published under the intended package name `@kodlab/kerna`. The adapter connects EmDash content, permissions, admin screens and tools to the framework-independent rules in `@kodlab/kerna-core`.

The plugin is unreleased and under development. A complete installation flow and stable API are not yet available on `main`. Do not install a similarly named npm package expecting this implementation.

See the root [contribution guide](../../CONTRIBUTING.md) for repository setup and package boundaries. Integration examples are developed with the implementation before a release.

## Development

- Install dependencies:

```bash
vp install
```

- Run the unit tests:

```bash
vp test
```

- Build the library:

```bash
vp run build
```
