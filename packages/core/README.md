# @kodlab/kerna-core

Kerna's framework-independent domain package. It is being built to own the Page format, validation, Operations, Proposals and the site's Design System. It must not import EmDash, Astro or React.

This package is unreleased and its API is under development. See the root [contribution guide](../../CONTRIBUTING.md) for repository setup and package boundaries.

## Development

- Install dependencies:

```bash
vp install
```

- Run the unit tests:

```bash
vp test run --coverage
```

- Build the library:

```bash
vp run build
```
